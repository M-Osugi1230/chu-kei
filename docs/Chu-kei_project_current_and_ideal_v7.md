## 2. Phase 0 Quality Rebase

2026-08-01に旧5つ星評価を廃止し、3,000社を再分類した。

- 315社: 非テンプレート型で再監査対象
- 2,685社: テンプレート型・深掘り前
- 610社: 資料名が決算短信等で、正式な中期経営計画を厳格に再探索する対象
- 353件 / 100社: 進捗レコードあり
- 258件 / 72社: 目標と実績を接続済み
- 自動Deep Verification承認は禁止

旧評価値は履歴としてのみ保持し、現行品質の分母・分子には使用しない。

## 3. Phase 1

Phase 1は正式資料が明確な50社で新工程を検証する工程として開始し、50社すべての一次レビューを完了した。

新工程では最低限、以下を分離して記録する。

- 正式中期経営計画か、Growth資料・単年度予想・長期ビジョンか
- 実績か、予想か、中計終端目標か
- 年度、単位、連結・単体等の範囲
- 戦略テーマ
- 財務目標
- 資本政策・キャッシュアロケーション
- 株主還元方針
- 項目別の証跡
- 一次レビューと独立レビュー

## 4. Phase 2

Phase 2は追加450社を対象とし、Phase 1と合わせて一次レビュー500社へ到達する工程である。

2026-08-15時点で:

- Phase 2一次レビュー: **370 / 450社（82.2%）**
- Phase 1込み: **420 / 500社（84.0%）**
- 残り: **80社**
- 最新完了Wave: **Wave 38**

80社を10社単位で処理できる場合、一次レビュー500社到達は Wave 39〜46 の8ウェーブが残る計算になる。ただし候補資料の誤紐付け、上場状態、資料不存在等を理由にウェーブ構成を変更する場合があるため、件数を優先して品質基準を緩めない。

## 5. Wave 38で得た重要な品質示唆

Wave 38では10社の一次レビューを完了した。このウェーブでは、候補資料の自動解決結果に5社の資料取り違えを検出し、公式正本へ差し替えた。

### 正式中計を確認

- 9404 日本テレビホールディングス: `中期経営計画2025-2027`
- 7649 スギホールディングス: `中期経営計画（2027年2月期～2031年2月期）`
- 1301 極洋: `Gear Up Kyokuyo 2027`
- 167A リョーサン菱洋ホールディングス: 5ヶ年経営計画

### 正式中計へ自動昇格しない

- 3566 ユニフォームネクスト: Growth資料＋2026年12月期単年度計画
- 2983 アールプランナー: Growth資料＋2027年1月期単年度計画
- 6557 AIAIグループ: Growth資料＋単年度予想＋M&A/PMI戦略
- 7674 NATTY SWANKYホールディングス: 2027～2029年の複数年事業計画はあるが、正式な「中期経営計画」とは明示されない
- 4689 LINEヤフー: 現行経営方針と5年間の株主還元方針を確認するが、今回確認したIR資料から正式中計としては昇格しない
- 9449 GMOインターネットグループ: 会社方針として中期経営計画を策定・公表しないことを明示

この結果、単年度予想、複数年の事業計画、長期目標、株主還元方針を「正式中計」と誤認するリスクをさらに下げた。

## 6. 現在の最大ボトルネック

一次レビューの残り80社よりも、品質面では独立図表レビューの滞留が大きい。

- 独立図表レビューpending: 306社
- Deep Verification最終承認: 0社

今後は一次レビューWave 39以降を進めながら、独立レビューを並行処理し、一次レビューだけが先行し続けないようにする。

## 7. 公開同期

GitHubを企業データ・出典・品質判断の正本とし、公開サイトはその公開ビューとする。

現状はQuality Rebase後のGitHub正本と公開サイトの品質表示が完全同期していない。公開同期は以下を満たした状態で行う。

1. 公開対象データが現行品質定義を使用する
2. 旧5つ星表示を現行のDeep Verification件数と混同しない
3. 3,000社掲載件数と深掘り確認件数を分けて表示する
4. 企業詳細に正式中計 / Growth資料 / 単年度予想等の資料区分を表示する
5. 出典URL・確認日・レビュー状態を表示する
6. 公開後にリンク切れ・レンダリング・検索・フィルタを再検証する

## 8. 次のマイルストーン

### Milestone A — Phase 2 一次レビュー 400 / 450

Wave 39〜41相当を進め、Phase 2を400社まで到達させる。

### Milestone B — Phase 2 一次レビュー 450 / 450

500社（Phase 1 50 + Phase 2 450）の一次レビューを完了する。現在から残り80社。

### Milestone C — 独立図表レビューの解消

古いWaveから独立図表確認を進め、年度・単位・図表の列見出し・実績/計画区分・資本政策の読み違いを再検証する。

### Milestone D — Deep Verification承認

一次レビューと独立レビューの双方を満たした企業から最終承認する。一次レビュアーによる自己承認は禁止する。

### Milestone E — 公開サイト同期

GitHub正本の品質状態を `chu-kei.com` へ反映し、公開後監査を完了する。

### Milestone F — 1,000社へ拡張

500社工程で得た誤資料率、差戻し理由、レビュー工数、独立確認のボトルネックを反映し、品質基準を維持したまま1,000社へ拡張する。

## 9. 品質ルール

- 会社公式PDFまたは会社公式IRページを一次資料として優先する
- 企業名・証券コード・資料名・公表日を確認する
- PDFは具体的ページ、Web資料は具体的見出し・URLを証跡として残す
- 正式中計、Growth資料、単年度予想、長期ビジョン、旧中計を分離する
- 実績、予想、中計終端目標を分離する
- 年度、単位、連結範囲を検査する
- 未開示値を推測で補完しない
- 比較不能なKPIに架空の進捗率を作らない
- 自動事実補完、自動承認、自動本番昇格を行わない
- 一次レビュアーは自分のレビューをDeep Verification承認しない
- 件数を増やすために品質基準を緩めない

## 10. 理想状態

> 日本企業の中期経営計画について、企業の発見、正式中計かどうかの判別、戦略比較、財務・資本政策比較、目標と実績の追跡、過去計画との差分、原文検証までを一つの場所で完結できる、信頼性の高い企業調査プラットフォーム。

## 11. 更新ルール

以下が変わった場合は、本基準文書、README、`effective-status-v1.json`、公開同期台帳を同じ変更単位で更新する。

- 掲載企業数
- Phase 1 / Phase 2 一次レビュー件数
- 独立レビュー件数
- Deep Verification承認件数
- 進捗・実績接続件数
- 品質基準
- 公開同期状態
