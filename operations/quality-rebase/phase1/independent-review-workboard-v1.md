# Phase 1 独立再確認ワークボード

更新日: 2026-08-01

## 承認原則

一次レビューの作成者とは別の確認者が、会社公式資料を最初から確認する。
一次レビューの文章を根拠として承認せず、必ず公式資料へ戻る。
以下がすべて完了するまで `deepVerificationApproved` を true にしない。

- 企業同一性
- 正式な資料種別
- 公表日・計画期間
- PDF全文または公式Web全文
- 戦略・財務目標・資本政策
- 年度・単位・連結範囲・セグメント範囲
- 実績・予想・中計目標・長期目標の分離
- 項目別ページ証跡
- 公式リンク到達性
- 公開ページの表示・検索・リンク

## レビュー記録ルール

各企業の独立レビューJSONへ以下を記録する。

- reviewerId
- reviewerType
- independentFromPrimaryReview = true
- reviewedAt
- 各 reviewChecks
- discrepancies
- decision.status
- decision.approved
- decision.reason

差異が1件でも残る場合は `changes_requested` とし、一次レビュー台帳へ戻す。
